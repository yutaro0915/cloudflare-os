プラグインを作り、公開し、使い、安全に外す。

スライドではありません。Playwright で実際の Chromium 画面を連続収録し、H.264 の動画として公開しています。

3本とも 1600×900 の連続した実画面収録です。作成候補が公開前にストアから隠れていること、別ユーザーによる権限確認付きインポート、再読込後の状態保持、安全なアンインストール、保持データの明示的な完全削除まで確認できます。

作成・隔離テスト・審査・公開

管理者が Incident Brief を実際に入力して作成し、生成マニフェスト、成果物ダイジェスト、Dynamic Worker 隔離テスト、署名を確認します。未公開候補を別の最終承認で公開し、権限確認後にインポートして Worker UI を開きます。

別ユーザーがインポートして使用

管理者が状態保持型の Release Board を作成・審査・公開し、サインアウトします。別ユーザー pluginreviewer としてサインインしたことをプロフィールで示し、正確なパッケージと権限を確認してインポート。タスクを追加・移動し、再読込後も Doing に残ることを示します。

状態を保持して安全にアンインストール

保持済みタスクから開始し、アクセス失効・ナビゲーション消失・データ保持という結果を確認してからアンインストールします。分離されたデータが残ったことを確認し、不可逆性を示す別の確認操作を経て完全削除します。
